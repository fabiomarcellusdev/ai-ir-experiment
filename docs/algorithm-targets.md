# Algorithm targets

A register of the methods the product leans on: each in plain words, the method used now, the better methods known,
and the trigger that brings each up. A target is looked at when its trigger fires, never on a whim, and never skipped
when it does. A new method keeps the old one as its test oracle.

| Target | In plain words | Now | Better methods known (with sources) | Trigger |
|---|---|---|---|---|
| <name> | <what problem it solves, for a non-engineer> | <the current method, or "none yet"> | <methods, each with a source> | <the event or measurement that brings it up> |
