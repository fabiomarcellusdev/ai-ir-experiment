## What the runs show

**C0.7 (large elements): the MCP arm used about half the tokens.**
- The MCP agent made the same 3 calls on 7 of 8 tasks: Glob, `html_find`, `html_edit`. `html_find` gives the lines
  of the matching element's ancestors with their refs, so the agent edited the large element by its ref with no
  read. On the 8th task it also called `html_read`.
- The baseline read the element and sent it back in full in its Edit's old text: 5 to 7 turns, and once 15 turns
  with 8 Edit calls.
- One baseline run failed fast (2 Grep calls, no edit, 14,466 tokens): its task's ratio is 1.53, and the gate's rule
  leaves that task out (no passed B run).
- No run had a missing-file error: the plain file names removed the C0.6 problem.

**C0.9 (quotes not in the source as written): no gain.**
- The baseline found the target with a Grep for a part of the quote, as often as the quote needed. Its turns stayed
  at 3 to 7.
- The MCP agent took Glob, `html_find`, `html_read` and then an edit: 4 to 6 turns. For a text or attribute change,
  `html_edit` must get the whole element again, so the agent first reads it.
- One task's quote comes from the raw text inside an `iframe` (the run plan's reading 7). Both arms passed it.

## What these numbers do not show

- **Previews decide nothing.** 1 run per task in each arm, 7 qualifying tasks each, files that were not drawn for
  these gates. A gate needs at least 20 qualifying tasks and 3 runs.
- **Only the current server.** The owner chose to test a new design with fewer, consolidated tools in the gates
  (contract amendment "the previews first", 3).
- **C0.8 has no preview.** Its cost is estimated from these two (below).

## C0.8's cost estimate (amendment "the previews first", 4)

The previews cost $0.035 a run (C0.7) and $0.012 a run (C0.9). A gate has 240 runs, so C0.8 would cost about $3 to
$8.50 at those rates. C0.8's MCP arm can read outline pages of up to 20,000 tokens, so the lead estimates **$3 to
$10**. The C0.8 gate runs only after the owner's yes for this estimate.
