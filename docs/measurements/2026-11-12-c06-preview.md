# C0.6 preview on C0.3's tasks: real agents, with and without the MCP server

**PREVIEW, not a gate verdict** (`docs/contract.md`, amendment "a C0.6 preview on C0.3's tasks"). With the C0.6 rules,
the preview's numbers would FAIL the token rule: the median token ratio M ÷ B is **1.45** (95% interval over files
1.14 to 1.92), and the gate needs 0.70 or less. Success is the same in both arms.

## Conditions

- Date: 2026-11-12 (UTC). Commit `5542392`. Claude Code 2.1.322, model `claude-sonnet-5-5`, the settings of
  `docs/measurements/2026-11-12-c06-run-plan.md`. NOT timed.
- Command: `node experiments/c06/run-c06.mjs --preview`, run one time, with no stop. Raw results:
  `experiments/c06/preview-result.json` (no text of a file).
- Inputs: C0.3's 10 files and 40 tasks (not C0.6 inputs), checked against their records. 1 run of each task in each
  arm: 80 runs, in one random order (seed `20261111`).
- Cost: **$0.85** in total (B $0.41, M $0.44).

By task type, success was 100% in both arms, except attribute changes in B (9 of 10). The one failed run changed the
canonical DOM.

**Tool use:** M used at least one MCP tool in 37 of 40 runs (92.5%). M's calls: Glob 42, `html_find` 38, `html_read`
30, `html_edit` 24, Edit 8, Grep 6, Read 3. B's calls: Grep 53, Edit 40, Glob 21, Read 19.

## Why M used more tokens

1. **The baseline did not read whole files.** In 0 of 40 runs did B read a whole file. It used Grep to find the
   quoted words, often read a few lines, and edited. C0.6's reason to expect a saving ("real agents read much more
   than the ideal path, for example whole files", contract, "Why these numbers") did not hold here.
2. **M took more turns.** A typical M run was Glob, `html_find`, `html_read`, `html_edit`: about 5 turns against B's
   3.5. Each turn sends the whole conversation again, and C0.6 counts each cached token as one token.
3. **M's fixed text is larger:** about 720 more tokens in each request, for the 4 tool definitions.

The dollar cost was about the same (B $0.41, M $0.44), because most tokens are cache reads, which cost a twentieth of
input tokens. C0.6 counts tokens, not dollars (contract, "What the rescope gates do not judge").

## What these numbers do not show

- **This is a preview.** C0.3's tasks, not C0.6's; 1 run per arm, not 3. It decides nothing.
- **The ideal path and real agents differ.** C0.5 passed at 0.374 on work tokens of the ideal path, which leave out
  the fixed text and count each call once. Real agents resend the context on each turn, and the baseline agent used
  Grep well.
- **Other models, prompts and harnesses** were not tested.
