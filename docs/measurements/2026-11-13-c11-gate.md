## What these numbers do not show

- **The real mix of a developer's work.** The mix is the owner's assumption (50% small edits). With 70% small edits,
  the estimate from the v2 gates' runs was higher (0.77 on the old server); this run measured mix A only.
- **New pages.** The tasks come from the v2 gates' task sets, so their files are pages that earlier gates used. Each
  run starts in a new process, with no memory of earlier runs.
- **Multi-step work.** Each task is one edit or one question on one file, with a prompt that names the target.
- **Other models, harnesses, or Claude Code's tool search** (off here; on, it did not pay: the arm-M checks).
- **Money.** The measure is tokens. In money, arm M cost $0.57 and arm B $2.34.
