# Gate C0.3 preview: proxy tokens on the frozen inputs

**PREVIEW, not the gate verdict.** Proxy token counts (contract amendment of 2026-11-11, "a proxy preview"). The
gate run with `count_tokens` on the same commit gives the verdict.

## Conditions

- Date: 2026-11-11. Commit `c5758a5` (the frozen inputs, `experiments/c03/run-inputs.json`). Node v24.22.1. NOT timed.
- Command: `node experiments/c03/run-c03.mjs --preview`. Raw results: `experiments/c03/c03-preview.json`.
- Inputs: the gate's 10 files and 40 tasks, the tool definitions and the paths of the run plan
  (`2026-11-11-c03-run-plan.md`).
- Tokens: the POC's two offline proxies (A: GPT-2-style, B: cl100k-style pre-tokenizer chunk counts) over the request
  text (the tools as JSON, then each block). Not Claude's tokenizer.

## Numbers

The ratio of a task is the MCP's cheapest valid path ÷ the baseline's cheapest valid path. The gate passes at a
median of 0.50 or less.

| Measure | Proxy A | Proxy B |
|---|---|---|
| Median ratio (40 tasks) | **0.657** | **0.647** |
| Quartiles (25%, 75%) | 0.55, 0.72 | 0.54, 0.71 |
| Range | 0.20 to 0.82 | 0.20 to 0.80 |
| Tasks at 0.50 or less | 4 of 40 | 4 of 40 |
| Median ratio, outline path only | 2.161 | 2.085 |
| Median ratio, find path only | 0.657 (valid in 40 tasks) | 0.647 (valid in 40 tasks) |
| Baseline's Grep path valid | 40 of 40 | 40 of 40 |

By task type (proxy A, median of 10 tasks): question 0.63, text change 0.70, attribute change 0.61, structure
change 0.66.

Median tokens of a task's cheapest path (proxy A): baseline 2,292; MCP 1,536. Median of the baseline's whole-file
path: 12,858. Median of the MCP's whole-outline path: 5,598.

## What the numbers show

- **The preview fails the gate.** The median is 0.65 against 0.50, with both proxies within 0.01 of each other. Only
  4 of 40 tasks are at 0.50 or less, and 3 quarters of the tasks are above 0.54.
- **The MCP saves about a third against a Grep-capable agent** (its find path against Grep plus a 41-line read).
- **The outline alone costs more than the Grep path:** about 2.1 times as much.
- **Against a whole-file read, the MCP's find path saves about 88%** (1,536 against 12,858 tokens, median). That is
  not what the gate measures: the gate's baseline takes its cheapest path.

## What the numbers do not show

- **Claude's real counts.** The gap to 0.50 is 0.15, and the proxies agree within 0.01, so a real count would have to
  differ a lot to change the verdict. The gate run checks it.
- **What a real agent does.** The paths are ideal. A real agent may read more than 41 lines, or the whole file; that
  is gate C0.4, which the contract runs only after C0.3 passes.
